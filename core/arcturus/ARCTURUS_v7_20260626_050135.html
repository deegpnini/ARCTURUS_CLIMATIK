Como funciona

Metodologia

Pipeline transparente e reproduzível — do dado bruto ao score final.

📡
Coleta de Dados
Artigos retratados coletados via OpenAlex API com filtro is_retracted:true excluindo avisos de retração. Controles pareados por área e período (2018–2023).
OpenAlex · Crossref
🧠
Feature Engineering
9 features textuais extraídas do abstract: comprimento, diversidade lexical, entropia de Shannon, taxa de repetição, comprimento de sentenças e o papermill_index — combinação ponderada de sinais suspeitos.
9 features · papermill_index
🌲
Modelo
Random Forest com 200 árvores e class_weight='balanced'. Sem escalonamento — RF é invariante a transformações monotônicas. Validação cruzada 5-fold estratificada.
Random Forest · 5-fold CV
🔒
Hold-out Externo
57 artigos separados antes de qualquer treinamento com seed fixo 2024. Nunca vistos pelo modelo durante desenvolvimento. Usados uma única vez para avaliação final.
57 artigos · seed 2024
⚖️
Limitações Declaradas
285 artigos é dataset pequeno. Especificidade baixa (falsos positivos). Features textuais simples não capturam fraude sofisticada. Escopo atual: 9 áreas biomédicas em inglês.
Triagem · Não diagnóstico
📖
Código Aberto
Pipeline completo disponível para reprodução. Dataset de treino baseado em abstracts públicos via OpenAlex. Preprint em preparação para OSF Preprints.
Open Source · OSF Preprint

Interpretabilidade

Importância das Features

Contribuição de cada feature para as decisões do modelo (Gini importance). Features estruturais dominam — o modelo aprende padrões de escrita, não tópicos.

Evolução

Roadmap

Do protótipo ao produto — cada versão com validação honesta.

v4.2 — v6.3
Prova de Conceito
Dataset inicial de 48 artigos → expansão para 285. Feature engineering, correção de bugs, pipeline de coleta via OpenAlex.
v7.0 · Atual
Validação Externa
Hold-out de 57 artigos separado antes do treino. Gap de 7.5 pp entre CV interno e externo. Generalização confirmada.
v8.0 · Em desenvolvimento
Preprint + Embeddings
Publicação no OSF Preprints. Dataset expandido para 500 artigos. Implementação de Sentence Transformers para análise semântica profunda.
v9.0 · Planejado
API Pública
Endpoint REST para submissão de DOIs. Dashboard Streamlit com explicabilidade SHAP. Análise de rede de coautoria.
v10.0 · Futuro
Produto Comercial
SaaS para editoras e instituições. Plano Starter e Pro. Auditoria institucional. Parceria com Retraction Watch.
