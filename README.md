# 🌪️ ARCTURUS CLIMATIK

**Sistema de Monitoramento Climático para Santa Catarina**

---

## 📋 Sobre o Projeto

ARCTURUS CLIMATIK integra dados de **45 estações meteorológicas** (21 EPAGRI + 24 INMET) em Santa Catarina, processando **1.052.136 registros** para previsão de temperatura, umidade e eventos extremos.

---

## 📊 Dados

| Fonte | Registros | Estações | Período |
|-------|-----------|----------|---------|
| EPAGRI | 352.296 | 21 | 2024-2026 |
| INMET | 699.840 | 24 | 2024-2026 |
| **Total** | **1.052.136** | **45** | 2024-2026 |

---

## 🧠 Modelos

- **Regressão (Temperatura):** RMSE 0.844°C, Skill 0.199
- **Classificação (Extremos):** Acurácia 0.95+
- **Anomalias (Isolation Forest):** Recall 1.00
